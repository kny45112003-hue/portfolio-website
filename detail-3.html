01 — Overview

Concept
Visual

한식진흥원 공식 사이트의 정보를 브랜드 중심으로 재구성했습니다.

행정 중심의 딱딱한 구조 대신, 생동감 있는 푸드 비주얼과 세련된 인포그래픽으로 한식의 매력을 전달하고, 핵심 사업 정보를 직관적으로 탐색할 수 있도록 설계했습니다.

시각적 몰입도 한식 고유의 색감과 신선함을 담은 고해상도 이미지를 전면에 배치하여 브랜드 정체성을 강화했습니다.
정보의 모듈화 나열식의 복잡한 사업 소개 문장들을 세련된 인포그래픽과 카드 UI로 구조화하여 가독성을 높였습니다.
사용자 중심 동선 한식 콘텐츠 홍보, 교육/인력 양성 등 핵심 메뉴로의 접근 단계를 대폭 축소하여 탐색 효율성을 극대화했습니다.

03 — Design Direction

Design
Direction

기존 행정 중심의 웹사이트 구조를 극복하고, 한식이 가진 풍부한 시각적 자산을 최대한 활용하여 브랜드 경험을 전면 재설계했습니다.

기존 사이트 (Before)
Pain Point
낮은 시각적 흥미
한식이라는 매력적인 소재를 다룸에도 불구하고 메인 화면이 일반 행정 사이트처럼 건조하게 구성되어 있었습니다.
과도한 텍스트 나열
핵심 사업 내용이 단순 불릿포인트와 표 형태로 빽빽하게 채워져 인지 피로도가 높았습니다.
낮은 정보 위계
메뉴와 서브 카테고리 간의 시각적 경계가 모호하여 원하는 정보를 찾기까지 동선이 복잡했습니다.
리디자인 (After)
🍱
스토리텔링형 풀 배너
페이지 상단에 깊이감 있는 한식 상차림 이미지를 배경으로 활용해 사이트 진입과 동시에 시각적 매력을 어필했습니다.
📊
인포그래픽 기반 순서도
복잡한 프로세스를 원형 라운드 UI와 대형 숫자를 활용해 한눈에 읽히도록 흐름을 재구성했습니다.
🌿
생동감 있는 비주얼 브랜딩
실제 조리 교육 및 글로벌 페스티벌 현장 이미지를 유기적으로 배치하여 생동감을 불어넣었습니다.
04 — Persona

Target
User

22
김지현
한식 글로벌 트렌드 연구에 관심 많은 대학생
목적
"공모전 준비를 위해 한식진흥원의 연구 자료와 진행 사업을 쉽고 명확하게 찾고 싶어요."
Pain Point
기존 사이트는 행정 서류처럼 글자가 너무 빽빽해 필요한 데이터를 한눈에 파악하기 어렵습니다.
Solution
인포그래픽과 넘버링 시스템으로 구조화된 사업 소개 화면을 통해 필요한 정보를 직관적으로 스캔합니다.
28
박민우
K-푸드 클래스를 기획하는 마케터
목적
"한식진흥원에서 주관하는 전문 교육이나 요리 경연 프로그램의 현장감과 신뢰성을 시각적으로 확인하고 싶어요."
Pain Point
실제 어떤 활동을 하는지 보여주는 이미지가 부족해 사업의 규모감이나 현장 분위기를 파악하기 힘듭니다.
Solution
스토리텔링형 풀 배너와 생동감 있는 현장 이미지 배치를 통해 기관의 전문성과 활동성을 한눈에 검증합니다.
