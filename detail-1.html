01 — Overview

Concept
Visual

대구 관광 공식 사이트의 정보를 여행자 중심으로 재구성했습니다.

딱딱한 공공기관 느낌 대신, 일러스트와 캐릭터를 활용해 대구만의 로컬 감성을 살리고, 관광지·골목길·음식·쇼핑 등 카테고리별로 정보를 직관적으로 구성했습니다.

정보의 가시성 복잡한 텍스트 위주의 나열에서 벗어나 이미지 중심의 배치로 시각적 가독성을 높였습니다.
현대적 감성 세련된 파스텔 톤의 테마와 여백의 미를 활용하여 감성적인 지역 관광 브랜드 이미지를 구축했습니다.
직관적 내비게이션 사용자가 원하는 여행 정보를 최소한의 동선으로 찾을 수 있도록 메뉴 구조를 직관적으로 재설계했습니다.

03 — Design Direction

Design
Direction

기존 공공기관 웹사이트가 가진 구조적 한계를 극복하고, 사용자가 대구의 매력을 온전히 느낄 수 있도록 레이아웃을 전면 개편했습니다.

기존 사이트 (Before)
Pain Point
경직된 레이아웃
공공기관 특유의 딱딱한 격자형 배치로 인해 콘텐츠의 매력이 반감되었습니다.
과도한 정보 노출
텍스트 위주의 과다한 정보가 한 화면에 집중되어 시선이 분산되는 문제가 있었습니다.
시각적 일관성 부족
다양한 크기의 배너와 일관성 없는 이미지 활용으로 인지 부하가 높았습니다.
리디자인 (After)
🖼️
대형 히어로 섹션
메인 상단에 대구의 감성을 담은 대형 비주얼 배너를 배치하여 사이트 진입 시 첫인상을 강화했습니다.
🗂️
콘텐츠 카드 UI
방대한 관광 정보를 카드 뉴스 형태로 모듈화하여 직관적이고 깔끔하게 정보를 전달합니다.
🧭
사용자 중심 레이아웃
스크롤 흐름에 따라 실시간 인기 명소, 축제 일정 등을 자연스럽게 탐색할 수 있도록 설계했습니다.

Target
User
